## 🌟 Game Overview

**Protest-n-Chase** combines Subway Surfers-style parkour agility with tactical team mechanics:
- **Choose Your Team**: Play as the agile **Protestors** raising viral awareness through megaphone chants, placard broadcasts, and human chains — or play as the **Delhi Police** deploying riot barricades, water cannons, and detainment buses.
- **Historic 3D Monument**: Faithfully recreated 3D environment of Delhi's **Jantar Mantar**, featuring the monumental **Samrat Yantra** sundial ramp, circular **Ram Yantra** observatories, sunken **Jai Prakash Yantra** marble bowls, and historic sandstone plazas.
- **Hybrid Solo & P2P Multiplayer**: Play solo against intelligent autonomous AI, or host/join real-time multiplayer lobbies using WebRTC PeerJS without any backend server.

## 🚀 Key Features

### 1. 🏛️ Authentic 3D Jantar Mantar Architecture
- **Samrat Yantra**: Colossal 30-meter high sundial ramp with steps and observation platform.
- **Ram Yantra**: Open-columned cylindrical astronomical structures with interior pillars.
- **Jai Prakash Yantra**: Sunken hemisphere bowl observatories with marble stairways.
- **Delhi Transit Vehicles**: DTC green-and-orange detainment buses and "Varun" riot water cannon trucks.

### 2. ⚡️ Subway Surfers-Style Agility & Evasion
- High-speed sprint with responsive stamina meter (`Shift`).
- Low parkour slide to duck under yellow steel barricades (`C`).
- Vaulting and jumping over obstacles (`Space`).
- Dynamic 3rd-person follow camera with 360° mouse orbit and first-person tactical modes (`V`).

### 3. ☕️ 3D Delhi Street Power-Ups & Collectibles
- ☕️ **Cutting Chai**: 100% stamina restore + 1.45x super sprint speed boost.
- 📢 **Amplifier Booster**: Doubles megaphone soundwave radius and shockwave reach.
- 📶 **5G Portable Hotspot**: 5x multiplier on live-stream awareness score.
- 🛡️ **Peace Aura**: 7-second grapple immunity shield.
- 🧯 **Traffic Cone Snuffer**: Smothers and extinguishes nearby tear gas canisters.

### 4. 🎮 Rapid-Tap QTE Minigames
- **Break-Free Struggle**: When grappled by police, mash `Spacebar` / rapid-tap the mobile screen button to break free with an evasive backflip!
- **Canister Kickaway**: Rapidly mash to deflect incoming tear gas canisters before detonation.

### 5. 📸 Cinematic Photo Booth & Poster Maker
- Press `P` anytime to freeze the action.
- Select from 5 aesthetic color grading filters: *Raw HDR*, *Golden Hour*, *Cyberpunk Night*, *1970s Vintage*, *Noir B&W*.
- Watermarked with official creator branding: `📢 PROTEST-N-CHASE • BY SHAZEB ANWAR KHAN`.
- Export high-resolution PNG posters directly to your device.

### 6. 📱 Cross-Platform Responsive Controls
- **Desktop**: Full WASD / Arrow keys, Space, Shift, C, Q, E, F, R, H, P, V, M.
- **Mobile & Touch**: 360° virtual analog joystick, dedicated jump/slide/sprint thumb buttons, and haptic feedback.

## 🛠️ Technology Stack

- **3D Graphics Engine**: [Three.js](https://threejs.org/) (r128+) with custom WebGL shaders, PCF soft shadows, dynamic sky dome, and particle physics.
- **Frontend Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) for reactive UI overlays, HUD, and modal sheets.
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom glassmorphism and modern dark aesthetic.
- **Icons**: [Lucide React](https://lucide.dev/).
- **Multiplayer Networking**: [PeerJS](https://peerjs.com/) (WebRTC DataChannels) for serverless P2P multiplayer.
- **Audio**: Web Audio API procedural sound synthesizer (megaphones, crowd chants, sirens, footsteps, water cannon).
- **Build Tool**: [Vite](https://vitejs.dev/) for instant HMR and optimized production bundles.

## 💻 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/shazeb-s-a-k/Protest-n-Chase.git

# Enter project directory
cd Protest-n-Chase

# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Open in browser: http://localhost:5173
```
